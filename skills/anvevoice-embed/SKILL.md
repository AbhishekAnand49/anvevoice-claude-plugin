# AnveVoice Voice Widget

Add this script before the closing </body> tag on your website:

<script src="https://api.anvevoice.app/functions/v1/voice-assistant-embed-js?embedId=YOUR_EMBED_ID&position=bottom-right&theme=light" async></script>

Get your Embed ID free at https://app.anvevoice.app

Options:
- position: bottom-right, bottom-left, top-right, top-left  
- theme: light, dark
