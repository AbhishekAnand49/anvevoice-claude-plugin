# AnveVoice — Claude Code Plugin

Add a real-time AI voice agent to any website in minutes.

## What it does

AnveVoice lets website visitors ask questions, book demos, fill forms, and take actions through natural voice conversation. Supports 50+ languages including Hindi and other Indian languages.
